# React Frontend — 4 Layer Architecture

=> Har layer ka sirf EK kaam hoga — "Single Responsibility"

```
UI Layer      => sirf screen dikhao, input lo, button dabao
    ↓
Hooks Layer   => kaam coordinate karo — API call karo, state update karo
    ↓
State Layer   => data store karo — user, loading, error
    ↓
API Layer     => backend se baat karo — axios yahan use hoga
```

=> Restaurant analogy se samajhte hain:

  UI Layer    = Waiter    — customer se order leta hai, khana deliver karta hai
  Hooks Layer = Manager   — waiter se order leta hai, kitchen ko batata hai
  State Layer = Order Board — kya ban raha hai, kya ready hai track karta hai
  API Layer   = Kitchen   — actual khana banata hai (backend se data laata hai)

=> Simple rules:

  UI    => sirf Hooks se baat kar sakta hai
  Hooks => State aur API se baat kar sakta hai
  State => kisi se baat nahi karta — sirf data store karta hai
  API   => sirf Backend se baat karta hai

=> Koi bhi layer SKIP nahi hogi!

## STEP 1 — API Layer banao

=> API Layer sirf backend se baat karegi — axios yahan use hoga
=> Baki kisi layer mein axios nahi hoga!

=> Pehle humara code aisa tha — REPEAT ho raha tha ❌

```javascript
// GALAT — har function mein same baseURL aur withCredentials repeat ho raha tha
export async function register(...) {
    const response = await axios.post("http://localhost:3000/api/auth/register",
        {...}, { withCredentials: true }); // baar baar repeat ❌
}

export async function login(...) {
    const response = await axios.post("http://localhost:3000/api/auth/login",
        {...}, { withCredentials: true }); // baar baar repeat ❌
}
```

=> Fix: `axios.create()` se ek custom instance banao — ek baar baseURL aur
   withCredentials set karo, phir baar baar likhne ki zaroorat nahi!


------------------------------------
src > features > auth > services > auth.api.js  (API Layer)
------------------------------------

import axios from "axios";
// axios import kiya — HTTP requests karne ke liye

// axios.create() se ek custom axios instance banao
// ab har request mein baseURL aur withCredentials automatically lagega!
// baar baar likhne ki zaroorat nahi
const api = axios.create({
  baseURL: "http://localhost:3000/api/auth",
  // baseURL = har request ke aage yeh URL automatically lag jaayega
  // eg: api.post("/register") => "http://localhost:3000/api/auth/register"
  // eg: api.post("/login")    => "http://localhost:3000/api/auth/login"

  withCredentials: true,
  // cookies automatically bhejenge aur receive karenge
  // bina iske token cookie mein set nahi hoga!
});

// =========================================================
// FUNCTION 1: register
// Kaam: Backend pe register API call karo
// Kaun use karta hai: State Layer (auth.context.jsx)
// =========================================================
export async function register(username, email, password) {
  try {
    const response = await api.post("/register", {
      // api.post => "http://localhost:3000/api/auth/register" pe POST request
      username,
      email,
      password,
    });
    return response.data;
    // response.data => backend ne jo JSON bheja woh return karo
    // eg: { message: "User Registered Successfully", user: {...} }
  } catch (err) {
    throw err;
    // error ko upar (State Layer) ko de do — yahan handle mat karo
  }
}

// =========================================================
// FUNCTION 2: login
// Kaam: Backend pe login API call karo
// Kaun use karta hai: State Layer (auth.context.jsx)
// =========================================================
export async function login(username, password) {
  try {
    const response = await api.post("/login", {
      // api.post => "http://localhost:3000/api/auth/login" pe POST request
      username,
      password,
    });
    return response.data;
    // eg: { message: "User LoggedIn Successfully", user: {...} }
  } catch (err) {
    throw err;
  }
}

// =========================================================
// FUNCTION 3: getMe
// Kaam: Currently logged in user ka data fetch karo
// Kaun use karta hai: State Layer (auth.context.jsx)
// =========================================================

export async function getMe() {
  try {
    const response = await api.get("/get-me");
    // api.get => "http://localhost:3000/api/auth/get-me" pe GET request
    // cookie mein token hai => backend identify karega ki kaun hai
    return response.data;
    // eg: { user: { username: "rahul", email: "...", ... } }
  } catch (err) {
    throw err;
  }
}

================================================

=> NOTE: Teri notes mein ek mistake thi login function mein!

  ❌ const response = await axios.post("/login", ...)
     // axios use kiya — api instance nahi!
     // withCredentials aur baseURL automatically nahi lagega!

  ✅ const response = await api.post("/login", ...)
     // api instance use karo — sab automatic! 😄

## STEP 3 — State Layer banao (auth.context.jsx)

=> State layer = shared whiteboard 📒
=> Koi bhi component user, loading dekh sakta hai
=> Sirf hooks likhenge isme — koi aur nahi!

=> State Layer mein kya hoga:
  - user => currently logged in user ka data
  - loading => API call chal rahi hai ki nahi
  - handleLogin => login ka kaam karta hai (actually yeh Hook ka kaam hai — neeche explain hai)
  - handleRegister => register ka kaam karta hai


------------------------------------------------
src > features > auth > auth.context.jsx  (State Layer)
------------------------------------------------

import { createContext, useState } from "react";
// createContext => context banane ke liye
// useState => data store karne ke liye

import { login, register, getMe } from "./services/auth.api";
// API layer ke functions import kiye
// State layer in functions ko call karegi

// =========================================================
// AuthContext banao
// Kaam: Poori app mein user aur loading share karo
// =========================================================

export const AuthContext = createContext();
// createContext() => ek context banao
// ab koi bhi component is context ko read kar sakta hai
// useContext(AuthContext) se

export function AuthProvider({ children }) {
// AuthProvider => ek wrapper component hai
// jo bhi components iske andar honge woh sab context read kar sakte hain

  // =========================================================
  // STATE — data yahan store hoga
  // =========================================================

  const [user, setUser] = useState(null);
  // user = currently logged in user ka data
  // null = abhi koi logged in nahi

  const [loading, setLoading] = useState(false);
  // loading = API call chal rahi hai ki nahi
  // false = abhi koi call nahi chal rahi


  // =========================================================
  // handleLogin — login ka kaam
  // =========================================================
  const handleLogin = async function (username, password) {

    setLoading(true);
    // loading true karo — UI mein "Loading..." dikhega

    try {
      const response = await login(username, password);
      // API layer ka login() function call karo
      // yeh backend pe POST /api/auth/login bhejega
      // response = { message: "...", user: { username, email, ... } }

      setUser(response.user);
      // state mein user save karo
      // ab koi bhi component user read kar sakta hai

      return response;
      // UI ko response return karo taaki woh navigate kar sake

    } catch (err) {
      console.log(err);
      throw err;
      // error UI ko de do taaki woh handle kar sake
    } finally {
      setLoading(false);
      // try ya catch kuch bhi ho — loading false karo!
      // finally hamesha chalta hai
    }
  };


  // =========================================================
  // handleRegister — register ka kaam
  // =========================================================
  const handleRegister = async function (username, email, password) {

    setLoading(true);

    try {
      const response = await register(username, email, password);
      // API layer ka register() function call karo
      // yeh backend pe POST /api/auth/register bhejega

      setUser(response.user);
      // registered user ko state mein save karo

      return response;

    } catch (err) {
      console.log(err);
      throw err;
    } finally {
      setLoading(false);
    }
  };


  return (
    <AuthContext.Provider value={{ user, loading, handleLogin, handleRegister }}>
    {/* AuthContext.Provider => yeh sab values poori app mein share karta hai */}
    {/* value mein jo bhi daalo woh koi bhi component useContext se read kar sakta hai */}
    {/* user => logged in user ka data */}
    {/* loading => API chal rahi hai ki nahi */}
    {/* handleLogin => login function */}
    {/* handleRegister => register function */}

      {children}
      {/* children => jo bhi components AuthProvider ke andar honge */}
    </AuthContext.Provider>
  );
}

================================================

=> NOTE: Teri notes mein auth.context.jsx mein API imports hain:
   `import { login, register, getMe } from "./services/auth.api"`
   Technically strict architecture mein State layer API import nahi karta —
   Hooks layer karta hai. But is codebase mein handleLogin aur handleRegister
   directly context mein likhe hain isliye yahan import hai — yeh ek simplified
   version hai. Aage proper hooks layer mein move ho sakta hai! 😄

## STEP 5 — Hooks Layer banao (useAuth.js)

=> Hooks layer = Manager
=> UI layer seedha Context nahi padhega — Hook ke through padhega
=> Kyun? Agar kal Context change ho jaaye — sirf hook badlega, UI nahi!


------------------------------------
src > features > auth > hooks > useAuth.js  (Hooks Layer)
------------------------------------

import { useContext } from "react";
// useContext => context read karne ke liye React hook

import { AuthContext } from "../auth.context.jsx";
// AuthContext import kiya — jisme user, loading, handleLogin sab hain

export function useAuth() {
  // useContext(AuthContext) => AuthContext ki saari values nikalo
  const context = useContext(AuthContext);
  // context = { user, loading, handleLogin, handleRegister }

  return context;
  // yeh sab values UI Layer ko de do
  // UI { handleLogin, loading, user } destructure karke use karegi
}

================================================

=> useAuth kyun banaya? Seedha useContext use kyon nahi kiya?
=>
  // Seedha useContext — har component mein yeh likhna padta
  const { handleLogin } = useContext(AuthContext); // baar baar repeat ❌

  // useAuth hook ke saath — ek baar likhne se sab mil jaata
  const { handleLogin } = useAuth(); // clean aur simple ✅

=> Aur agar kal AuthContext ka naam badal jaaye — sirf useAuth.js mein
   badlana padega — har component mein nahi! 💪

## STEP 6 — Login.jsx update karo (UI Layer)

=> Ab Login.jsx mein axios nahi hoga!
=> Sirf useAuth() hook call karega aur handleLogin use karega
=> navigate() bhi add kiya — login ke baad "/" pe jaao


------------------------------------
src > features > auth > pages > Login.jsx  (UI Layer)
------------------------------------

import React, { useState } from "react";
import "../style/form.scss";
import { Link } from "react-router";

import { useAuth } from "../hooks/useAuth";
// useAuth hook import kiya — Hooks Layer se
// handleLogin aur loading iske through milega

import { useNavigate } from "react-router";
// useNavigate => programmatically navigate karne ke liye
// eg: login ke baad "/" pe bhejo

const Login = () => {

  // =========================================================
  // LOCAL STATE — sirf is component ke liye
  // =========================================================
  const [username, setUsername] = useState("");
  const [password, setPassword] = useState("");


  // =========================================================
  // HOOKS
  // =========================================================
  const { handleLogin, loading } = useAuth();
  // handleLogin => Hooks Layer se mila — login ka kaam karega
  // loading => State Layer se mila — API chal rahi hai ki nahi

  const navigate = useNavigate();
  // navigate("/") => "/" route pe jaao bina page reload ke


  // =========================================================
  // LOADING CHECK
  // =========================================================
  if (loading) {
    return <h1>Loading...</h1>;
    // agar API call chal rahi hai => poora form ki jagah "Loading..." dikhao
    // loading State Layer mein hai — handleLogin ne true kiya tha
  }


  // =========================================================
  // handleSubmit — jab Login button dabaya jaaye
  // =========================================================
  function handleSubmit(e) {
    e.preventDefault();
    // page reload rokko

    handleLogin(username, password)
    // Hooks Layer ka handleLogin call karo
    // yeh internally:
    //   1. loading = true set karega (State Layer)
    //   2. API Layer ka login() call karega
    //   3. response.user State Layer mein set karega
    //   4. loading = false set karega

      .then((res) => {
        // login successful =>
        console.log(res);
        navigate("/");
        // "/" pe navigate karo — home page pe bhejo
        setUsername("");
        setPassword("");
        // fields empty karo
      })
      .catch((err) => {
        // login failed — eg: wrong password (401), user not found (404)
        console.log(err);
        setUsername("");
        setPassword("");
      });
  }

  return (
    <main>
      <div className="form-container">
        <h1>Login</h1>

        <form onSubmit={handleSubmit}>
        {/* form submit hone pe handleSubmit chalega */}

          <input
            value={username}
            // value prop zaroori hai — React controlled input ke liye
            // setUsername("") karne ke baad field empty hogi tabhi
            onInput={(e) => setUsername(e.target.value)}
            type="text"
            name="username"
            placeholder="Enter username"
          />

          <input
            value={password}
            onInput={(e) => setPassword(e.target.value)}
            type="password"
            name="password"
            placeholder="Enter password"
          />

          <button type="submit">Login</button>

        </form>

        <p>
          Don't have an account?
          <Link className="toggleAuthForm" to="/register">
            Register
          </Link>
          {/* Link => /register pe jaao bina page reload ke */}
        </p>

      </div>
    </main>
  );
};

export default Login;
