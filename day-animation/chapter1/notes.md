Animation:: 
*   It is a illusion of motion.
-> starting point 
-> ending point
-> duration
-> easing : How the object move from starting point to ending point.
-> path of the animation: Straight line, curved line, etc.




Web Animation:: 
* It is a animation that is created using web technologies.
* It is used to create animation on web pages.
* CSS animation and JS animation.
* CSS animations are limited
* JS animation is powerful but it needs lot of lines of code also we need to optimize ourselves.

GSAP : Animation Library:: 
* It is a animation library that is used to create animation on web pages.
* It is a JS library.
