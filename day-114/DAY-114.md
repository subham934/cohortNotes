Aaj Day-114 hai. Aaj hum implement karenge:

  1. Token Blacklisting — logout ke baad token invalidate karo
  2. getMe API — logged in user ka data fetch karo
  3. Logout API — user ko logout karo
  4. Password security — response mein password nahi aana chahiye

=> Pehle quick concept:

  JWT token ek baar ban jaaye toh valid rehta hai jab tak expire na ho
  Agar user logout kare — cookie toh delete hogi but token abhi bhi valid hai!
  Koi bhi us token ko use karke API access kar sakta hai — SECURITY RISK! ❌
  Solution => Token Blacklisting ✅


==========================================


## Token Blacklisting kya hota hai?

=> Logout pe token ko ek special collection "blacklist" mein store kar dete hain
=> Har request pe check karte hain — "kya yeh token blacklist mein hai?"
=> Agar hai => access deny karo! ❌
=> Agar nahi => access do! ✅

```
User logout karta hai
    |
    v
Token cookie se delete karo (client side)
    |
    v
Token blacklist DB mein save karo (server side)
    |
    v
Koi bhi us token se request kare =>
Middleware check karega => blacklist mein hai => 401 Unauthorized!
```

=> NOTE: Production mein token blacklisting MongoDB mein nahi — **Redis** mein ki jaati hai!
=> Redis bahut fast hai — har request pe DB check karna slow hota hai
=> Is project mein hum MongoDB use kar rahe hain — concept samajhne ke liye!

const blacklistSchema = new mongoose.Schema(
  {

      type: String,
      required: [true, "Token is required for blacklisting"],

      // ❌ unique: [true, "Token must be unique"] — yeh galat hai
      // ✅ unique: true — yeh sahi hai
    },
  },
  {

    // createdAt aur updatedAt automatically add hoga
    // createdAt se pata chalega kab token blacklist hua
  },
);

const blacklistModel = mongoose.model("blacklist", blacklistSchema);

module.exports = blacklistModel;

## STEP 2 — Auth Middleware banao

=> Middleware 2 kaam karega:
  1. Token verify karega — valid hai ya nahi
  2. Token blacklist mein hai ya nahi check karega


----------------------------------------
Backend > src > middlewares > auth.middleware.js
----------------------------------------

const jwt = require("jsonwebtoken");
const blacklistModel = require("../models/blacklist.model");
// blacklistModel import kiya — token check karne ke liye
// NOTE: teri notes mein userModel import tha — but yahan use nahi hota! ❌

async function authUser(req, res, next) {

  // LINE 1: Cookie se token nikalo
  // jab tak user login nahi karta — uske paas token nahi hoga
  const token = req.cookies.token;

  // LINE 2: Token nahi hai toh 401 bhejo
  if (!token) {
    return res.status(401).json({
      message: "Token not provided",
    });
  }

  // LINE 3: Token blacklist mein hai ya nahi check karo
  // agar blacklist mein hai => koi logout kar chuka hai is token se
  // => access deny karo!
  const isTokenBlacklisted = await blacklistModel.findOne({ token });
  if (isTokenBlacklisted) {
    return res.status(401).json({
      message: "Invalid Token — please login again",
    });
  }

  // LINE 4: Token verify karo
  // jwt.verify 2 kaam karta hai:
  //   1. Token valid hai ya tampered/expired hai check karta hai
  //   2. Token ke andar ka data nikalta hai — { id, username }
  try {
    const decoded = jwt.verify(token, process.env.JWT_SECRET);
    req.user = decoded;
    // req.user mein { id, username } store ho gaya
    // ab koi bhi controller req.user se user ka data read kar sakta hai!
    next();
    // next() => request agle step (controller) pe forward karo

  } catch (err) {
    return res.status(401).json({
      message: "Invalid token",
    });
  }
}

module.exports = { authUser };

## STEP 3 — User Model update karo

=> Problem: DB se user fetch karte waqt **password bhi aa jaata hai** — yeh DANGEROUS hai!

=> 2 solutions hain:

---

### Solution 1 — Controller mein `.select("-password")` use karo

```javascript
// sirf getMe controller mein password hide karo
const user = await userModel.findById(req.user.id).select("-password");
// "-password" => password field mat bhejo response mein
```

---

### Solution 2 — Model mein hi `select: false` lagao (BETTER) ✅

=> Yeh zyada safe hai — **by default** password kabhi bhi response mein nahi aayega!


--------------------------------------
Backend > src > models > user.model.js
--------------------------------------

const mongoose = require("mongoose");

const userSchema = new mongoose.Schema({
  username: {
    type: String,
    required: [true, "Username is required"],
    unique: true,
  },
  email: {
    type: String,
    required: [true, "Email is required"],
    unique: true,
  },
  password: {
    type: String,
    required: [true, "Password is required"],
    select: false,
    // select: false => by default password KABHI bhi response mein nahi aayega!
    // yeh sabse safe approach hai
  },
});

const userModel = mongoose.model("user", userSchema);

module.exports = userModel;

================================================

=> But ek problem aayegi — **login ke waqt password compare karna padta hai!**
=> `select: false` lagane ke baad — `findOne()` mein password nahi aayega
=> Fix: Login mein explicitly `.select("+password")` likhna padega

## STEP 4 — Auth Controller banao

=> Controllers:
  1. registerUser — user register karo
  2. loginUser — user login karo
  3. getMe — logged in user ka data fetch karo
  4. logoutUser — user logout karo + token blacklist karo


---------------------------------
Backend > src > controller > auth.controller.js
---------------------------------

const userModel = require("../models/user.model");
const bcrypt = require("bcryptjs");
const jwt = require("jsonwebtoken");
const blacklistModel = require("../models/blacklist.model");
// blacklistModel import kiya — logout mein token blacklist karne ke liye


// =========================================================
// FUNCTION 1: registerUser
// Kaam: Naya user register karo
// =========================================================
async function registerUser(req, res) {
  const { username, email, password } = req.body;

  // Check karo ki user already exist karta hai ya nahi
  const isAlreadyRegistered = await userModel.findOne({
    $or: [{ username }, { email }],
    // $or => username ya email mein se koi bhi match kare
  });

  if (isAlreadyRegistered) {
    return res.status(400).json({
      message: "Username or email already exists",
    });
  }

  // Password hash karo — plain text store karna DANGEROUS hai!
  const hashedPassword = await bcrypt.hash(password, 10);
  // 10 = salt rounds => 2^10 = 1024 rounds of processing

  // User DB mein save karo
  const user = await userModel.create({
    username,
    email,
    password: hashedPassword,
  });

  // JWT token banao
  const token = jwt.sign(
    {
      id: user._id,       // user ka unique id
      username: user.username,  // username bhi store karo
    },
    process.env.JWT_SECRET,
    {
      expiresIn: "3d",    // token 3 din baad expire hoga
    },
  );

  res.cookie("token", token);
  // token cookie mein store karo — browser automatically bhejega har request mein

  return res.status(201).json({
    // 201 = "Created" — naya resource successfully bana
    message: "User registered successfully",
    user: {
      id: user._id,
      username: user.username,
      email: user.email,
      // password nahi bheja — security! ✅
    },
  });
}


// =========================================================
// FUNCTION 2: loginUser
// Kaam: User login karo
// =========================================================
async function loginUser(req, res) {
  const { email, password, username } = req.body;

  const user = await userModel.findOne({
    $or: [{ email }, { username }],
  }).select("+password");
  // .select("+password") => model mein select:false lagaya tha
  // login mein password compare karna padta hai isliye explicitly mangaya
  // bina iske password nahi aayega aur bcrypt.compare fail ho jaayega!

  if (!user) {
    return res.status(400).json({
      message: "Invalid credentials",
    });
  }

  // Password verify karo
  const isPasswordValid = await bcrypt.compare(password, user.password);
  // bcrypt.compare => entered password ko hash karke DB ke hash se compare karta hai

  if (!isPasswordValid) {
    return res.status(400).json({
      message: "Invalid credentials",
    });
  }

  // JWT token banao
  const token = jwt.sign(
    {
      id: user._id,
      username: user.username,
    },
    process.env.JWT_SECRET,
    {
      expiresIn: "3d",
    },
  );

  res.cookie("token", token);

  return res.status(200).json({
    message: "User logged in successfully",
    user: {
      id: user._id,
      username: user.username,
      email: user.email,
      // password nahi bheja! ✅
    },
  });
}


// =========================================================
// FUNCTION 3: getMe
// Kaam: Currently logged in user ka data fetch karo
// =========================================================
async function getMe(req, res) {

  // authUser middleware ne pehle se req.user set kar diya tha
  // req.user = { id: "...", username: "..." }
  const user = await userModel.findById(req.user.id).select("-password");
  // .select("-password") => password field response mein mat bhejo
  // double safety — model mein bhi select:false hai

  return res.status(200).json({
    message: "User fetched successfully",
    user,
  });
}


// =========================================================
// FUNCTION 4: logoutUser
// Kaam: User logout karo + token blacklist karo
// =========================================================
async function logoutUser(req, res) {

  // LINE 1: Cookie se token nikalo
  const token = req.cookies.token;

  // LINE 2: Client side se cookie delete karo
  res.clearCookie("token");
  // clearCookie => browser se token cookie delete ho jaayegi
  // but yeh sirf client side se delete hoga — token abhi bhi valid hai!

  // LINE 3: Token ko blacklist mein save karo — server side protection
  // Koi bhi iss token ko use kare => middleware block kar dega!
  await blacklistModel.create({ token });
  // ab yeh token DB mein "blacklisted" hai

  return res.status(200).json({
    message: "User logged out successfully",
  });
}

module.exports = { registerUser, loginUser, getMe, logoutUser };

const { Router } = require("express");
// Router directly destructure kiya — same as express.Router()
// NOTE: teri notes mein commented code tha — clean version yeh hai

const authController = require("../controller/auth.controller");
const authMiddleware = require("../middlewares/auth.middleware");

const router = Router();

// POST /api/auth/register
router.post("/register", authController.registerUser);

// POST /api/auth/login
router.post("/login", authController.loginUser);

// GET /api/auth/get-me — [protected]
// authMiddleware.authUser pehle chalega — token verify karega
// phir authController.getMe chalega — user data return karega
router.get("/get-me", authMiddleware.authUser, authController.getMe);

// POST /api/auth/logout — [protected]
// NOTE: logout ke liye POST use karna chahiye — GET nahi!
// GET request URL mein visible hoti hai — security risk!
// POST request body mein data bhejti hai — safe!
router.post("/logout", authMiddleware.authUser, authController.logoutUser);
// authMiddleware.authUser isliye — sirf logged in user hi logout kar sake!

module.exports = router;

IMPORTANT NOTE — Redis vs MongoDB for Blacklisting:

  MongoDB (Abhi use kar rahe hain):
    - Har request pe DB query hogi — SLOW ❌
    - Simple implementation ✅
    - Learning ke liye theek hai ✅

  Redis (Production mein use karo):
    - In-memory storage — BAHUT FAST ✅
    - Token TTL (Time To Live) automatically set kar sakte hain ✅
    - Scalable ✅
    - Industry standard ✅

  => Concept same hai — sirf storage alag hai!
